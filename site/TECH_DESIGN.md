# YUKINGS 案例页 技术设计文档

## 一、技术栈

HTML5 + 原生CSS + 轻量化JS；图片格式WebP，开启懒加载；禁止iframe、大型外部框架。

## 二、核心代码统一规则（新增强制项）

### 2.1 样式代码统一

1.  禁止新建独立CSS类名，**直接复用产品详情页现有CSS类**，保证样式100%同步；如需补充样式，仅在原有样式基础扩展。
2.  响应式媒体查询：断点（桌面/平板/手机）、适配规则、样式优先级，完全复刻产品详情页媒体查询代码。
3.  全局样式：字体、颜色、边距、边框、阴影等基础样式，继承全站产品页通用样式表。

### 2.2 HTML结构统一

1.  页面整体DOM结构、标签层级、模块包裹规则，参考产品详情页代码结构。
2.  表单、按钮、表格、图片、列表等标签写法，与产品详情页保持一致。
3.  结构化数据（JSON-LD）格式、嵌入位置，沿用产品详情页规则。

### 2.3 脚本统一

轻量化交互JS（悬浮按钮、表单验证、下载跳转），直接复用产品详情页脚本代码，不重新编写。

## 三、项目结构（TRAE SOLO 生成规范）

每个案例页为独立HTML文件，命名规则：case-序号-项目英文名.html
目录结构：
/pages/case-studies/ （对应Shoptop二级栏目路径）

## 四、页面通用技术规则

1.  响应式：使用媒体查询，适配 桌面/平板/手机 三端
2.  加载优化：图片懒加载、代码精简，页面加载≤2.6s
3.  样式复用：全局统一样式类，保证15个页面样式完全一致
4.  表格：使用原生HTML表格，适配移动端横向滚动

## 五、平台适配规则（Shoptop 专属）

1.  代码：仅使用标准HTML/CSS，禁止iframe、外部复杂脚本
2.  表单：对接Shoptop原生表单系统，字段一一对应
3.  链接：站内内链使用Shoptop站内相对路径
4.  路由：URL 格式统一：域名/case-studies/项目短名称

## 六、合规技术要求

1.  GDPR：表单增加数据授权勾选框，页面底部添加隐私政策链接
2.  Cookie：页面兼容Shoptop原生Cookie弹窗

## 七、SEO 技术配置

1.  图片ALT 属性：强制填写
2.  Meta 标签：每个页面独立 Title / Description
3.  结构化数据：内嵌 CaseStudy 类型 JSON-LD
4.  路由：短URL，无特殊字符

## 八、补充校验项

代码完成后，对比产品详情页代码：CSS类名、标签结构、媒体查询、组件代码无差异化。
