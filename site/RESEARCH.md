# YUKINGS 声屏障案例 - 需求研究

## 1. 项目背景

为YUKINGS海外Shoptop独立站批量开发15个声屏障工程案例页，归属「案例中心」二级栏目，面向欧美公路/铁路/工业基建工程师、工程采购商。

## 2. 目标用户

1.  技术端：关注欧盟认证、声学参数、材质、抗风防腐、检测报告、施工工艺
2.  采购端：关注项目规模、履约能力、工期、全周期ROI、质保、询盘对接

## 3. 核心目标

1.  视觉：极简高端工业风，严格遵循品牌VI；**案例页与全站产品详情页视觉、排版、组件完全统一**
2.  内容：基于Excel原始数据，全英文专业文案，使用国际标准单位
3.  运营：谷歌SEO优化、站内闭环内链、提升询盘与资料下载转化
4.  合规：满足欧盟GDPR、Cookie隐私法规
5.  适配：PC/平板/移动端全响应，兼容Shoptop原生功能

## 4. 固定页面模块（通用）

首屏Banner → 项目概览 → 难点&解决方案 → 技术参数 → 项目成果 → 信任背书 → 关联案例 → 底部CTA表单

## 5. 强制统一规则（新增核心）

### 5.1 视觉统一

案例页所有配色、字体、字号、行高、留白、卡片样式、表格样式、图标样式、图片展示规则，**完全沿用现有产品详情页标准**。

### 5.2 组件统一

按钮、表单、卡片、分割线、图片组、下载按钮、悬浮CTA、列表样式，与产品详情页组件样式一致。

### 5.3 代码统一

CSS类名、样式规则、HTML标签结构、响应式媒体查询规则，复刻产品详情页代码规范，不新增独立样式。

## 6. 约束条件

1.  仅使用Excel原始数据，禁止编造参数、资质、文案；无中式营销话术
2.  图片优先实景WebP图，禁用3D渲染图、中文水印
3.  自然植入关键词：industrial sound barrier、highway noise barrier、railway acoustic barrier
4.  严格对齐产品详情页设计规范，不得自定义样式与布局
